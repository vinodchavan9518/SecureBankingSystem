# SecureBankingSystem
Secure Bank Management System developed using Java, JSP, Servlet, JDBC, and MySQL with features like user authentication, OTP-based money transfer, and transaction management.
  
  
## Project Description
Secure Banking System is a Java project used for banking operations.

## Features
- User Login
- Deposit Money
- Withdraw Money
- Balance Check
- Transaction History

## Technologies Used
- Java
- JDBC
- Oracle Database
- VS Code

## How to Run
1. Open project in VS Code
2. Run Java files
3. Connect Oracle database
4. Start application
